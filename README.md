# Python Master: Интерактивный тренажер тестирования и сертификации (MTA 98-381)

Интерактивное веб-приложение, созданное на основе PDF-теста по Python (`TESTE python.pdf`), включающее **244 вопроса**, все вырезанные иллюстрации, правильные ответы и подробные пояснения на русском языке.

---

## 🚀 Способы запуска

### Способ 1: В один клик (Windows)
Просто запустите файл **`start_trainer.bat`** двойным кликом:
- Автоматически запустится локальный сервер на порту 8080.
- В браузере сразу откроется страница `http://localhost:8080`.

### Способ 2: Напрямую в браузере (без сервера)
Просто откройте файл **[`index.html`](file:///c:/Users/jokre/Desktop/practica/index.html)** двойным щелчком мыши в любом браузере (Google Chrome, Яндекс.Браузер, Microsoft Edge, Firefox).
> Благодаря подключению `questions.data.js`, сайт работает офлайн и локально даже по протоколу `file:///`.

### Способ 3: Через терминал / Python
```bash
python -m http.server 8080
```
Затем перейдите в браузере по адресу: **http://localhost:8080**

## 🌟 Основные возможности и функционал

1. **Два полноценных режима:**
   - **Режим тренировки:** мгновенная подсветка правильного (зеленый) и ошибочного (красный) ответа, отображение подробного авторского разбора, возможность посмотреть подсказку («Показать ответ») или случайный вопрос.
   - **Режим экзамена:**
     - Настройка пресетов: *Стандарт MTA 98-381* (45 вопросов / 45 мин), *Экспресс-тест* (25 вопросов / 25 мин) или *Полный марафон* (все 244 вопроса).
     - Таймер обратного отсчета с предупреждающей анимацией при <5 мин.
     - Вопросы без мгновенной подсветки до момента сдачи.
     - Итоговый экран с процентом сдачи (порог 70%), временем, детальной статистикой по всем 6 темам и кнопкой «Работа над ошибками».

2. **Работа над ошибками и Избранное:**
   - Вопросы, на которые дан неверный ответ, автоматически попадают в фильтр **«Ошибки»**.
   - Любой сложный вопрос можно пометить звездочкой (кнопка `★` или клавиша `S`), чтобы повторить позже через вкладку **«Избранное»**.
   - Прогресс и статистика сохраняются в `localStorage` вашего браузера.

3. **Все типы вопросов:**
   - Классический одиночный выбор (A, B, C, D).
   - Множественный выбор («Choose two / three») с кнопкой подтверждения.
   - Вопросы формата **Yes / No** (интерактивная таблица утверждений).
   - Вопросы на сопоставление и выпадающие списки (Dropdown / Drag-and-drop).

4. **Работа с иллюстрациями:**
   - Все 95 иллюстраций извлечены из PDF в высоком качестве и размещены в папке `images/`.
   - Картинки отображаются прямо под формулировкой вопроса.
   - Реализован модальный просмотр: клик по картинке открывает ее в полноэкранном масштабе.

5. **Навигация и фильтрация:**
   - Интерактивная сетка (палитра) вопросов с цветными индикаторами статуса (пройдено, ошибка, текущий, в избранном).
   - Быстрый переход по номеру вопроса (1–245) или поиск по ключевым словам.
   - Фильтрация по 6 официальным разделам экзамена:
     1. *Operations using Data Types and Operators*
     2. *Flow Control with Decisions and Loops*
     3. *Input and Output Operations*
     4. *Code Documentation and Structure*
     5. *Troubleshooting and Error Handling*
     6. *Operations using Modules and Tools*

6. **Премиальный дизайн и адаптивность:**
   - Современный темный режим по умолчанию с неоновыми акцентами, мягкими тенями и эффектом стекла (Glassmorphism).
   - Переключатель темной и светлой темы.
   - Адаптивная верстка: удобно заниматься как на широкоформатном мониторе, так и с мобильного телефона или планшета.
   - Звуковые эффекты (Web Audio API без внешних аудиофайлов).
   - Горячие клавиши на клавиатуре (`A`/`D` или `←`/`→` для навигации, `1-4` для выбора ответа, `S` для избранного, `H` для подсказки).
